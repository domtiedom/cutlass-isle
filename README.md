# Cutlass Isle

A tiny pirate roguelite that runs in any browser — no install, no internet needed. Inspired by Dead Cells: fight room by room (doors slam shut until the room is cleared), roll to dodge, drink flasks to heal, and beat Captain Blackfin at the end of the isle.

## How to play

1. Download `cutlass-isle.zip` from this page (Code → Download ZIP, or the direct link below), unzip it, and double-click `index.html`. It opens in the browser.
2. Or open `index.html` straight from this repository.

## Controls

| Key | Action |
| --- | --- |
| Arrows / WASD | Move |
| Space / W | Jump (press again in the air to double jump) |
| Z | Cutlass combo (3-hit) |
| X | Roll (invincible while rolling) |
| C | Pistol |
| E | Drink flask (heals) |
| P | Pause |
| M | Mute |

Touch buttons appear automatically on tablets.

## Goal

Clear each room to open its doors, grab gold and treasure chests, then defeat **Captain Blackfin** in the last room.
